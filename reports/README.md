# System Reports & Validation Output Directory

This folder stores automated validation reports, system health logs, and performance audit deliverables generated by the test runner and backend validation scripts.

---

## Included Reports

- **`master_validation_report.json`**: End-to-end master validation report summarizing pass/fail status across all 6 core AI modules.
- **`module1_validation_report.json`**: Detailed validation audit report for UAV image acquisition, EXIF/GPS parsing, and quality scoring algorithms.
- **`module1_test_report.json` through `module5_test_report.json`**: Individual test execution outputs for dataset loaders, detector models, change metrics, and S-Curve predictors.

---

*Note: Confidential client documents, proprietary site CAD files, or sensitive personal credentials should never be committed to this folder.*
