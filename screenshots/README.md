# Application Screenshots & UI Showcase

This folder contains user interface screenshots demonstrating the end-to-end features of the UAV Construction Progress Monitoring system.

---

## Screen Directory

1. **`dashboard.png`** — Main executive summary overview showing total projects, active inspections, global progress score, and quick alerts.
2. **`project_workspace.png`** — Project details tab displaying timeline milestones, baseline S-Curve vs actual progress curve, and scheduled completion metrics.
3. **`inspection_page.png`** — Inspection management workspace showing past flight sessions, uploaded image counts, and quality assessment breakdowns.
4. **`uav_upload.png`** — Drag-and-drop UAV flight image batch uploader supporting raw multi-spectral and RGB aerial images.
5. **`image_validation.png`** — Real-time image validation view highlighting blur detection scores, exposure warnings, EXIF/GPS coordinate extraction, and resolution compliance.
6. **`ai_analysis.png`** — YOLOv8 object detection interface identifying construction workers, PPE safety equipment (hard hats, vests), machinery, and raw material stockpiles.
7. **`change_detection.png`** — Bi-temporal change detection workspace comparing pre-construction (Time T1) and post-construction (Time T2) aerial pairs with highlighted change masks and IoU metrics.
8. **`progress_results.png`** — Automated progress assessment dashboard displaying calculated completion percentage, component progress rates, and milestone delay scores.
9. **`delay_prediction.png`** — Machine learning delay risk predictor forecasting completion dates, bottleneck risks, and weather/supply chain impact models.
10. **`explainable_ai.png`** — Explainable AI (XAI) tab showing Grad-CAM spatial activation heatmaps over changed construction zones and SHAP feature importance charts.
11. **`report_generation.png`** — Automated PDF report generator interface previewing generated executive reports with embedded XAI visual evidence.

---

*Note: Screenshots can be captured directly from the running web interface (`http://localhost:5000/`) and saved into this folder.*
